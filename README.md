#Parent Child EM

Define Parent Child Relation between two arms.

## Description
This REDCap External Module enables a parent-child relationship between project arms, simplifying data management when multiple arms need hierarchical associations.

## Installation
1. Place this folder into the REDCap modules directory (e.g., redcap/modules/).
2. Enable the module on the Control Center → External Modules page.
3. Configure the module in your project under Project Setup → External Modules.

## Usage
1. Go to the module’s configuration page to set up the parent arm and child arm.
2. Use the module’s provided interface to link records between arms.
3. Generate reports that show parent-child relationships.
